# California Housing Price Prediction

## Project Overview
This project uses Machine Learning regression models to predict median house values in California based on housing data.

## Objectives
- Explore and understand the dataset.
- Clean and preprocess the data.
- Perform Exploratory Data Analysis (EDA).
- Apply Feature Engineering.
- Train and evaluate regression models.

## Models
- Linear Regression
- Extra Trees Regressor

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Evaluation Metrics
- R² Score
- Mean Absolute Error (MAE)

## Project Structure
- `California_Housing_Prediction.ipynb`: Main notebook containing the analysis and models.
- `requirements.txt`: Required Python libraries.
- `images/`: Project visualizations.

## Results
- Linear Regression R² Score: 0.68
- Extra Trees Regressor R² Score: [0.8173]
- MAE: [32569.8]
